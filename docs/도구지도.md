## 1. 가장 중요한 발견

**같은 AI 모델을 여러 플랫폼이 동시에 팔고 있습니다.** [사실]
- Seedance(영상)는 CapCut·Runway·Higgsfield에서 쓸 수 있습니다.
- Nano Banana(이미지)는 Runway·Higgsfield·CapCut·Adobe Firefly(무료 일일 생성 포함)에서 쓸 수 있습니다.
- Kling(영상)은 Runway·Higgsfield에서 쓸 수 있습니다.

→ [제안] 그래서 **모델이 아니라 "작업 흐름이 편하고 이미 쓰는 플랫폼"으로 도구를 고르는 것**이 맞습니다. 모델 순위는 매달 바뀌어도, 플랫폼을 옮길 필요는 적습니다.

## 4. 판단 규칙 — "이 상황엔 이 도구" [제안]

| 상황 | 1순위 | 이유 |
|---|---|---|
| 글자가 중요한 카드뉴스·썸네일 | Claude(HTML) → Canva | 글자를 이미지가 아닌 텍스트로 넣어야 수정할 수 있고 오타가 없음 |
| 분위기·일러스트 이미지 | ChatGPT(GPT Image) | 이미지 품질 1위권. 이미 구독 중이면 추가 비용 없음 |
| 같은 캐릭터가 반복 등장 | Ideogram 또는 Higgsfield | 캐릭터 일관성 기능을 내세움 (실제 품질은 테스트 필요) |
| 글자·도형이 움직이는 모션 | Claude Motion → Canva | 둘 다 연결돼 있어 바로 가능 |
| 짧은 실사 영상 장면(B-roll) | CapCut Pro (Seedance 포함) | 편집 도구 안에서 생성까지 해결. 진입 비용이 가장 낮음 |
| 한국어 내레이션 | Typecast vs ElevenLabs **직접 비교 후 결정** | 순위표가 한국어를 평가하지 않음 |
| 자막·컷 편집 | Vrew 또는 CapCut | 한국어 음성 인식 자막 |
| 최종 조립 | 이미지형은 Canva, 영상형은 CapCut | 조립하는 곳은 한 곳으로 정해야 일관성이 유지됨 |

## 5. 시작 세트 예시 (SNS 본진, 하루 2~3시간) [제안]

- Claude(이미 사용 중) + Canva Pro(월 약 ₩8,250) + CapCut Pro(₩25,000) + Typecast 베이직(₩9,900)
- 추가 비용은 **월 약 ₩43,000**입니다. 이미 내고 있는 구독이 있으면 그만큼 줄어듭니다.
- ChatGPT Plus를 이미 쓰고 있으면 이미지는 ChatGPT로 해결하고, 다른 이미지 도구는 추가하지 않습니다.

## 6. 아직 모르는 것 [미확인]

- 형석님이 지금 결제하고 있는 도구 → 시작 세트가 달라집니다.
- 한국어 음성 품질 (Typecast vs ElevenLabs) → 같은 원고로 직접 비교 테스트가 필요합니다.
- Kling·Figma 정확한 가격, Google(Veo·Gemini) 직접 사용 경로
- 각 도구의 상업 이용 조건 세부 (무료 플랜은 출처 표기 의무 등 제약이 있음. 예: Typecast 무료)
