# 한국어 음성 비교 테스트 (Typecast vs ElevenLabs)

목적: 릴스 내레이션에 쓸 음성 도구 하나를 고릅니다. 두 도구 모두 **무료 플랜으로 테스트**하고, 결제는 결과를 본 뒤에 합니다.

## 테스트 원고 (약 30초, 그대로 복사해서 사용)

> 아이가 말을 할 때, 혹시 이런 고민 있으신가요?
> "우리 아이 발음, 이대로 괜찮을까?"
> 걱정하지 마세요. 집에서 하루 5분이면 충분히 시작할 수 있어요.
> 첫째, 아이 눈높이에서 천천히 말해 주세요.
> 둘째, 틀려도 고쳐 주기보다 정확한 소리를 한 번 더 들려주세요.
> 셋째, 오늘 잘한 것 하나를 꼭 칭찬해 주세요.
> 더 많은 놀이 방법은 프로필 링크에서 확인하세요!

원고에 일부러 넣은 시험 요소: 질문 억양, 따옴표 속 혼잣말, 숫자("5분", "첫째·둘째·셋째"), 영어 외래어("프로필 링크"), 다정한 감정 톤.

## 방법

1. 두 사이트에 형석님이 직접 무료 가입합니다. 가입과 로그인은 제가 대신 할 수 없습니다.
   - Typecast: typecast.ai/kr
   - ElevenLabs: elevenlabs.io
2. 각 도구에서 **다정한 30~40대 여성 목소리**와 **차분한 남성 목소리**를 하나씩 골라 위 원고를 생성합니다.
3. 파일을 받아 `assets/reference/voice-test/`에 넣습니다. 파일 이름 예: `typecast-여성.mp3`, `eleven-남성.mp3`
4. 휴대폰 스피커로 들어 봅니다. 릴스는 대부분 휴대폰으로 듣기 때문입니다.
5. 아래 표를 채웁니다. 제가 채워 드릴 수는 없고, 형석님 귀가 기준입니다.

## 평가표 (1~5점)

| 항목 | Typecast | ElevenLabs |
|---|---|---|
| 발음이 정확한가 (숫자·외래어 포함) | | |
| 억양이 자연스러운가 (질문·혼잣말) | | |
| 감정이 원고와 맞는가 (다정함) | | |
| 사람 같은가 (기계음이 덜한가) | | |
| 만들기가 편했나 | | |
| **합계** | | |

## 결제 전 확인할 조건

- Typecast 무료 플랜: 체험 보이스만 쓸 수 있고, 출처를 표기해야 합니다. 상업적 사용은 베이직(₩9,900/월)부터 가능합니다.
- ElevenLabs 무료 플랜: 상업 라이선스는 Starter($6/월, 첫 달 $1 행사 11/1까지)부터 포함됩니다.
